# Use this file instead of requirements.txt when running on a GPU machine.
#
# TWO IMPORTANT DIFFERENCES FROM requirements.txt
# -----------------------------------------------
# 1. torch is NOT listed here.
#    GPU servers and NVIDIA NGC containers ship with a CUDA-enabled torch
#    already installed and tuned for that machine. Reinstalling it usually
#    downgrades or breaks it. Check what is there first:
#
#        python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
#    Anything from torch 2.1 upward works with this project.
#
# 2. numpy is NOT pinned.
#    A preinstalled torch is compiled against a specific numpy major version.
#    Forcing numpy 1.26 onto a container built for numpy 2.x breaks torch with
#    confusing errors. Leave whatever the container provides.
#
# Install with:
#     pip install -r requirements-gpu.txt
